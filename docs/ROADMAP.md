# Roadmap

These are planned milestones, not completed features.

1. **Contribution foundation:** public repository, proposal templates, shared design, review checks and enforced main protection.
2. **Platform and rights:** select initial dependencies (or original-only), pin one supported platform, choose project license, and establish maintainer ownership.
3. **Playable bootstrap:** minimal mod, repeatable builds, dedicated server and two-client test, installation instructions.
4. **First connected loop:** obtainable raw material, basic processing, starter ritual, catalyst, and one useful machine upgrade. Prove no circular unlocks.
5. **Contributor pilot:** three small proposals through review and staging; improve instructions based on actual friction.
6. **Private alpha:** measured capacity, permissions/claims design, progression persistence, backup restoration and integrated playtests.
7. **Viewer release:** numbered client/server distribution, support and update instructions, monitored rollout.

Good first proposals: first-loop recipe graph; canonical material/tag plan; visual style examples using original assets; test scenarios; accessibility requirements; external-mod compatibility research.
