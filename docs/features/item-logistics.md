# Item logistics

Status: implemented in source (PR #15); **not yet played**. Compiles in CI; three game tests cover it.
Proposal issue: none; the owner selected "Logistics" directly on 30 September 2026.
Owner: @jimbozoomer-byte
Target milestone and tier: Workshops (technology), after brass (metal press plates)
Primary specialty and supported player role: engineering, factory building

## Player experience
Machines stop needing a hopper on every side:

- **Side configuration:** choose on each machine's screen which faces take ingredients in, which give results out, both, or neither.
- **Eject:** turn it on and a machine pushes its results out by itself.
- **Brass item pipes** join machines, chests and other mods' inventories into a network.
- The **Pneumatic Extractor** pulls from a chest or machine.
- The **Item Sorter** sends only the items in its filter to the inventory it faces.
- A **Brass Wrench** turns and dismantles machines.

Details and numbers: [TECH_TREE.md → Item logistics](../TECH_TREE.md#item-logistics).

## Connections
- Existing input producer: brass (alloy smelter) pressed into plates (metal press); hoppers, comparators and glass.
- Existing output consumer: every processing machine, chest and inventory, including those of other mods through Fabric's `ItemStorage`.
- Technology connection: automation for every processing line.
- Magic connection: none yet. Any future magic inventory that exposes `ItemStorage` joins automatically.
- Reachable entry path: brass needs the alloy smelter and the plates need the metal press, both of which come before any logistics block. Nothing here is needed to reach either.
- Required vs optional: fully optional. Hoppers still work, and the side defaults match the old behavior.
- How this specialty stays useful: it automates earlier work without replacing it.

## Balance and automation
- The extractor and eject each move 16 items every 8 ticks: 2 items per tick per pusher.
- Pipes are passive and move items instantly. Only pushers set the rate.
- Pipes cost 2 brass plates + glass for 6.
- Nothing is created or destroyed. Items that fit nowhere stay in their source.

## Multiplayer and persistence
- Server-authoritative. The side buttons send only a button ID, and the server validates it (`SideConfig.click`).
- Side configuration is saved with the machine (`"sides"`); older saves get the defaults.
- Networks are found by a bounded search (at most 1,024 pipes), cached per level, and rebuilt when a pipe or its neighbors change.
- A multi-block machine never ejects into itself.
- Disable behavior: logistics blocks are gated by the `machines` switch (recipes only; placed blocks stay).
