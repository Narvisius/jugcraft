# Jimtafacts meteorites and compact explosives

Local implementation by OpenAI Codex, 23 October 2026. Builds, runtime generation and gameplay tests are deferred until the combined Jimtafacts pass is finished. Nothing in this record claims a completed playtest or release.

The native meteorite structure keeps the supplied spacing32, separation8, salt124895654 and50% source generation gate. It samples terrain variance, chooses an original2–8-block core radius, carves the source paraboloid crater and places the asymmetric sky-stone shell. Inside are original quartz blocks and four budding grades, small/medium/large buds, and a mysterious reward cube. Biome temperature, snow, precipitation and ocean conditions select ordinary, water, lava, obsidian, snow or ice variants. Original sand/glass, badlands and snow/ice fallout and shoreline filling are adapted to the normal structure pass. Each call writes only its generating chunk, leaves bedrock and existing block entities intact, and never rewrites existing chunks.

The original mysterious cube models, textures and animation sidecars are used. Breaking one yields all four reusable inscriber presses and the native Engineer's Handbook; Silk Touch preserves the cube. The handbook replaces the source external guide integration. The core supplies a second acquisition route alongside the existing native production recipes.

A vanilla compass becomes a meteorite compass in the existing charger for1000JE. The original three-dimensional base and pointer retain their face geometry and UVs. The pointer uses128 native mesh poses, original6-block arrival distance and source0.5-second/3-second fast/slow spin periods. It locates reward cores within2048blocks in terrain that has been loaded, not arbitrary sky-stone blocks. A saved per-dimension core index, updated on chunk load/place/remove, uses256-block spatial buckets,289 bucket lookups and at most4096 candidates per cached search; it never force-loads terrain. A world can index65,536 cores. This replaces the source threaded disk-region compass service, and the practical range/index limit is explicit.

Tiny TNT retains the supplied8×8×8-pixel model, original texture,80-tick fuse, ignition by flint/fire charge, redstone, burning projectile, dispenser and neighboring explosion, shrinking blast pattern and6damage hit. Water returns one unprimed item, including on its last fuse tick. Its original final10-tick swelling and five-tick white flash are rendered. Native ownership persists through saving and redstone ignition; every affected block checks current claims and town protection, and player-caused damage checks PvP and party rules. Anonymous/dispenser charges can only break unclaimed blocks and do not harm living creatures. The source TNT sound's unusually high pitch is adapted to a bounded pitch2, and grounded bounce uses the vertical axis. No parallel permission or damage framework is introduced.

Source inputs remain under `art/owner-library/originals/Oct23/Jimtafacts/applied energentics reborn by jimbo/`. Geometry/assets are copied by `tools/jimtafacts_network_exploration.py`; source behavior was statically inspected from meteorite, compass and tiny-TNT classes with trusted CFR, never executed. Asset contract tests and three native game tests are authored for the combined final run. Remaining verification includes new-chunk biome variants and seams, actual compass direction in each hand/display context, claim boundaries, save/restart ownership and the reward core loot codec.
