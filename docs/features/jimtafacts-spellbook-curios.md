# Supplied spellbook curios

Owner-directed continuation, 23 October 2026. Implemented with OpenAI Codex; local only. Builds and tests remain deferred until the combined Jimtafacts implementation is finished.

All 21 supplied ring/necklace IDs now have native accessory classes: mana and silver rings, cooldown and casting rings, heavy chain, emerald stoneplate, fire/frost/poison wards, both conjurers' talismans, affinity ring, concentration amulet, lurker, amethyst resonance, invisibility, expulsion and visibility rings, teleportation amulet, betrayer signet and wicked bone ring. Items work when equipped in ordinary Trinkets slots, with no research prerequisite. Carrying an item or wearing a cosmetic copy grants no ability. The existing grave/keep-inventory integration owns their death handling.

The original layered sprites, teleportation pearl animation and nine school-specific affinity ring appearances are imported without pixel edits. The source supplied these curios as item models/icons, not a new body-attached animated character model. Modern item model dispatch replaces the source affinity ring's custom inventory renderer.

The mana conversion preserves the source proportions: the source's base 100 mana maps to the existing base 20 Focus, so the two rings add 20 and 5 maximum Focus. This extends the same saved Focus pool and hard capacity limit used by other magical gear. Equipping a ring does not fill it, removing one clamps excess capacity, and reequipping does not restore clipped points. The resonance charm adds fractional regeneration while worn and below capacity; it cannot bank points while full. No second spendable mana currency is introduced.

Source cooldown/cast reductions retain their diminishing-return formula. Summon damage, interruption protection, projectile ricochets, eldritch power and selected-spell affinity use the spellbook system's explicit hooks. The greater talisman exempts natural summon expiration from recast cooldown; it does not fabricate an extra summon allowance. The invisibility ring lets its wearer see invisible entities. The teleportation amulet grants the already-implemented Evasion effect for three seconds; the old source power prerequisite is intentionally omitted under the owner's no-item-use-gates instruction.

Affinity loot retains optional school filters and only selects source spells whose configured maximum exceeds one. Native spell effects apply the selected level where the corresponding working has level scaling; fixed-step working limitations remain recorded in the spellbook feature inventory. A blank or previously attuned ring can also be rebound by using it with a supported scroll in the other hand, consuming one scroll. Its selected spell and original appearance survive normal item persistence.

Fire/frost/poison and visibility wards are server-authoritative. Heavy chain reduces magical harm; emerald stoneplate modifies actual creature XP. Lurker and betrayer bonuses have shared per-wearer cooldowns and obey the existing PvP/party/claim rules. The signet's mana-sensitive damage uses player Focus capacity above the native base, not an invented hidden mana attribute on every monster. Expulsion scans at most 16 nearby living targets, requires line of sight and existing harm permissions, and never damages blocks. Full knockback resistance remains effective.

The source class and asset paths remain under `art/owner-library/originals/Oct23/Jimtafacts`. Runtime provenance is included by the spellbook generator. Six focused game tests and three resource tests are written for the final combined run: equipment/slot access, capacity conservation, wards, affinity school/consumption, visibility/timing, claims/cooldowns, original texture fidelity, all affinity appearances and additive slot tags. None has been run for this continuation yet.
