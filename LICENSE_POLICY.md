# License and contribution rights

The project owner has not selected a project license yet. This foundation does not grant an open-source license or claim ownership of third-party content. Public visibility alone is not a blanket permission to reuse code or assets.

Before implementation or asset PRs are accepted, maintainers must publish a LICENSE, decide any separate asset terms, and update the contribution policy to explain the license under which contributions are accepted. Until then, proposals and documentation review can proceed; code/assets are gated.

Contributors must provide original or appropriately authorized work and record source, author, license and modifications for third-party material. Never copy proprietary mod code or redistribute another mod's JAR just because it is downloadable. AI-generated content must still be reviewed for provenance and rights.
