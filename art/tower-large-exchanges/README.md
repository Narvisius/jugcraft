# Large tower exchanges

Original native art by OpenAI Codex (GPT-6), 9 October 2026, MIT.

Both new variants occupy nine blocks across, six deep and five tall. Each has 270 parts in y/z/x order and the front functional connection at canonical part58, model coordinates `(72,24,0)`. The energy exchange uses new dedicated charcoal/black material IDs, neutral concrete, normal-sized engraved instruments, a continuous switchgear enclosure, a sealed taller transformer and connected supported cooling banks. The cargo exchange remains a fully enclosed black/charcoal box, with a gray mineral plinth, independent service covers, roof hatches, backed vents, attached hinges/pulls and an integrated fitted item bulkhead. There is no conveyor, open inspection tunnel, fake product or baked live value.

`tools/tower_large_exchanges.py` is a standalone targeted generator. It exposes `footprint()`, `geometry(energy)`, `layout(energy)`, `native_parts(energy)`, `item_elements(energy)`, `write_assets(root)`, `check_assets(root)` and `preview()`. Run it with `--write --check --preview`. It writes only new `energy_exchange_large_part0..269`, `cargo_exchange_large_part0..269`, large item models, separate large telemetry/collision metadata and new `tower_power_large_*` textures. Java owns blockstates, registration, game logic and layout selection.

The existing original instrument drawings are reused at their original size, with the complete live bank translated32modelpixels along X. Both ports retain their real cable/pipe fitting size: energy's rubber boot is6.4pixels across and cargo's brass neck is6pixels across, meeting the external block boundary at z0. All other live-plane coordinates, fonts, lamp radii and meter scales retain their original dimensions. Separate large metadata records the exact contract and six energy/three cargo coarse collision boxes.

Existing small models, materials, metadata, item models and generators are preserved. Cargo references its existing neutral materials; tower steel/concrete/rubber references preserve their existing provenance. New power originals are original author-derived instrument/material assets, recorded in `provenance.json`, and copied byte-for-byte to runtime. No third-party, owner-library or screenshot pixels were imported. The owner asset catalog was reviewed.

Native audits cover all parts and inventory models for closed surfaces, UV bounds, native model bounds, coplanar surfaces and cross-part seams. Additional readback checks verify both fitted necks at z0, normal-sized controls, and the continuous enclosed cargo shell. Preview images read the exported JSON and PNGs with back-face culling and a depth buffer. They are offline native asset reviews; Minecraft validation is reported by the integrating task.
