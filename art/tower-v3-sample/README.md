# Drone Tower material and model revision sample

The owner rejected the first runtime visual pass on 8 October 2026 because it still looked like the original blocks and a toy. The approved tower concept remains the realism target. This small sample tests new actual materials and model construction before expanding the revised visual language across the tower.

This is a work sample, not a completed tower redesign or an in-game screenshot. The source materials below are original images generated with the built-in OpenAI image-generation tool. They are kept unchanged; the native models use their UV regions across continuous architectural surfaces.

- `cast_concrete_albedo.png`: 1254 x 1254, original generated concrete material.
- `painted_structural_steel_albedo.png`: 1254 x 1254, original generated painted steel material.
- Source images remain in the user's Codex generated-images directory; these project copies are the durable sample sources.
- Models and previews are generated by `tools/tower_realism_v3.py` into the build sample directory. An offline exported-model preview is not gameplay evidence.

The owner approved this native material and geometry sample. The runtime pipeline in `tools/tower_realism_runtime.py` now installs power-of-two derivatives of these materials, with phased UVs across two-metre building sections. These original source images remain unchanged. No unrelated drone artwork or owner-library originals are modified. See [the runtime art record](../../docs/features/drone-tower-industrial-art.md) for the full implementation and asset checks.

## Concrete image prompt

Create an original realistic seamless diffuse albedo of dark cool-gray poured architectural concrete, a continuous two-metre square patch. Fine mineral aggregate, tiny air voids, subtle cured cement variation and faint formwork impressions. Uniform diffuse light, straight-on, edge to edge. No panel border, frame, bricks, bevel, whole-face grooves, text, perspective, specular shine or directional shadows. Real industrial material rather than cartoon/pixel art. Restrained imperfections, no exaggerated grunge.

## Painted steel image prompt

Create an original realistic seamless diffuse albedo of heavy industrial structural steel with aged dark charcoal/gunmetal matte factory paint, a continuous two-metre square patch. Fine mill texture, subdued industrial mottling, tiny occasional scratches and sparse rubbed abrasion revealing dull gray steel. Even diffuse light, straight-on and edge to edge. No panel outline, bevel, screws, rivets, words, logos, stripes, directional lighting or reflections. No orange rust carpet or decorative distressed noise. Readable broad value at distance and fine realistic detail close up.
